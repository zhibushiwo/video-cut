# 变更日志（CHANGELOG）

> **职责**：记录**用户可见**的功能与行为变更（新增、变更、修复、移除），按版本成段。
> **唯一真源**：用户可见变更的对外表述以本文为准；**实现级细节**在各批次提交与 [handoff-archive.md](./archive/handoff-archive.md)，本文不重复。
> **读时机**：发版前整理发布说明；用户问"这版有什么变化"。
> **写规则**：只记用户可见项；只追加不重写历史段；开发中的变更先进 `[Unreleased]`，发版时切成 `[x.y.z] - YYYY-MM-DD`。**不抄 git log**（工程面改动如 lint/重构/文档整理不入本文）；**修复类条目须引 `BUG-0NN`**。
> **关联**：[INDEX.md](./INDEX.md) · 进度 [PLAN.md](./PLAN.md) · 缺陷 [BUGS.md](./BUGS.md) · 历史实现 [handoff-archive.md](./archive/handoff-archive.md)
> **最后更新**：2026-10-14（切 0.3.0：工作台双列布局/预览拖高/框选放大推广/设置三分区/日志文件夹/BUG-028/029 修复等；0.2.0 已于 2026-10-11 发布）——发版说明以版本段为准，历史头部注记迁 [archive/handoff-archive.md](./archive/handoff-archive.md)（2026-10-11 头部瘦身）

格式遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，分类固定为：新增 / 变更 / 修复 / 移除。

## [0.3.0] - 2026-10-14

### 新增
- **预览面板高度拖拽**（M21）：工作台与剪切/合并预览底边可拖拽调高，双击复位、重启记忆；预览默认更高
- **框选放大推广**（M21）：合并页、剪切页与成品渲染预览同样支持 Ctrl+拖拽框选放大（原仅播放器）
- **日志文件夹**（M20）：设置页可一键打开日志文件夹；检查更新、GPU 探测、模型列表失败会写入日志，便于排查网络与环境问题

### 变更
- **工作台双列布局**（M21）：素材池与片段池左右双列各占一半、内容各自滚动，时间轴缩矮腾出预览空间
- **设置页三分区**（M21）：改为「通用 / AI 字幕 / 关于」三个标签页
- **检查更新通道修订**（M20）：直连 GitHub API 检查版本、失败详情写日志；更新下载显示进度，按钮语义改「下载并安装」
- **损坏文件提示优化**（M21）：打不开的视频不再倾倒整屏技术输出，改为一句话说明（可能已损坏或不完整）
- **播放器细节**（M21）：预览拖高后画面不被控制条遮挡；倍速文字与图标对齐

### 修复
- **打开设置弹系统错误框**（M20，`BUG-028`）：已下载 GPU 加速包但无 N 卡的机器上，打开设置会弹「找不到 nvccuda.dll」系统对话框——启动时全局抑制加载器硬错误弹窗，探测失败改为可判读退出码
- **检查更新失败 missing field 'url'**（M20，`BUG-029`）：网络劫持/污染导致更新检查解析失败——更新端点双通道容错 + 失败写日志，可在日志看到实际报错
