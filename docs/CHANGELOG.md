> **唯一真源**：用户可见变更的对外表述以本文为准；**实现级细节**在各批次提交与 [handoff-archive.md](./archive/handoff-archive.md)，本文不重复。
> **读时机**：发版前整理发布说明；用户问"这版有什么变化"。
> **写规则**：只记用户可见项；只追加不重写历史段；开发中的变更先进 `[Unreleased]`，发版时切成 `[x.y.z] - YYYY-MM-DD`。**不抄 git log**（工程面改动如 lint/重构/文档整理不入本文）；**修复类条目须引 `BUG-0NN`**。
> **关联**：[INDEX.md](./INDEX.md) · 进度 [PLAN.md](./PLAN.md) · 缺陷 [BUGS.md](./BUGS.md) · 历史实现 [handoff-archive.md](./archive/handoff-archive.md)

## [0.4.0] - 2026-10-25

### 新增
- 剪切页「合并输出」：提取的多个片段可直接按顺序合成一个视频（极速无损拼接 / 精确帧级重编码两种模式都支持），不再逐片段出独立文件
- 合并页「分组无损合并」：参数不一致时按参数自动分组，各组各自无损合并（并发执行），参数独特的文件跳过并提示
- 合并页分组勾选：分组以卡片展示（组内文件与总时长），默认全选、取消勾选的组不提交
- 剪切页片段截图：片段列表每条可一键截取片段中点帧为 png（全分辨率，落到输出目录）
- 剪切页 GIF 导出改片段级：片段列表每条「导出 GIF」按该片段区间出图（原页脚选区入口移除——选区易在添加片段后变化造成误解）
- 剪切页预览面板拖高：底边拖拽调高、双击复位、跨重启记忆（与工作台同款交互）
- 片段再编辑：剪切页片段列表每条可「编辑」——区间回填选区重新定点后保存替换（Esc 取消）
- 「播放」页：只看不编的本地播放器——Ctrl+拖拽局部缩放/平移、水平/垂直翻转（仅观看）、倍速 0.2~3、循环播放、记住每个视频的上次播放位置
- 播放页增强：↑↓ 音量/M 静音/F 全屏/双击全屏/S 截图快捷键、跳转指定时间（支持 h:mm:ss / mm:ss / 秒）、最近播放列表（重开应用后接着上次看）、窗口标题随视频名、视频信息卡
- 纯音频转字幕：mp3/m4a/wav 等音频文件可直接导入字幕页识别出 .srt
- GIF 短片段导出：剪切页框选区间一键导出 GIF 动图（fps 15、长边 ≤480、两遍调色板；无音轨）
- 导出目录临时更改推广到合并/工作台/编辑页（字幕页已有）：默认仍走输出目录规则，本次可临时改，一键恢复
- 设置页新增「烧录样式默认」：字幕烧录的字号/描边/底边距可设默认值，字幕页自动带入
- 时间轴自适应：短片段不再铺满整条时间轴（自动留白，手动缩放与「适应窗口」不受限）

### 变更
