# 变更日志（CHANGELOG）

> **职责**：记录**用户可见**的功能与行为变更（新增、变更、修复、移除），按版本成段。
> **唯一真源**：用户可见变更的对外表述以本文为准；**实现级细节**在各批次提交与 [handoff-archive.md](./archive/handoff-archive.md)，本文不重复。
> **读时机**：发版前整理发布说明；用户问"这版有什么变化"。
> **写规则**：只记用户可见项；只追加不重写历史段；开发中的变更先进 `[Unreleased]`，发版时切成 `[x.y.z] - YYYY-MM-DD`。**不抄 git log**（工程面改动如 lint/重构/文档整理不入本文）；**修复类条目须引 `BUG-0NN`**。

## [0.2.0] - 2026-10-11

### 新增
- **应用内检查更新与自动更新**（M20）：设置页可手动检查更新；开启「启动时检查更新」（默认开）后每次启动静默查询新版本（仅访问 GitHub，失败无声）；发现新版本后可在应用内下载（带进度）并一键重启安装，更新包经签名校验（`FR-398`，`ADR-046`）
- **软字幕无损封装**（M18-12）：字幕页新增第二导出出口——把 .srt 作为软字幕轨封装进新容器，视频/音频原样复制（秒级、画质不变、多音轨全保留），播放器里可随时开关字幕；mp4 系源输出 `_softsub.mp4`，其余源输出 `.mkv`
- **字幕烧录样式**（M18-13）：烧录可设置字号 / 描边 / 底部边距（留空 = 默认样式，超范围自动收敛）
- **字幕页预览与信息**（M18-14）：选中视频即出预览，识别后同一预览位叠加字幕；信息卡显示时长/大小/分辨率等 + 按模型预估识别耗时
- **模型管理迁设置页**（M18-14）：模型下载/删除/GPU 加速包/打开模型文件夹移入设置页「AI 字幕」区，字幕页只保留选择
- **预览实时框选放大**（M19）：播放器内 Ctrl+拖拽框选画面区域即时放大，拖拽平移，Esc/双击还原（仅预览，不影响导出）
- **播放器控制栏改版**（M19）：B 站样式——细进度条置顶、播放按钮、合并时间码、倍速菜单、音量悬停滑条
- **导出目录临时可选**（M19）：字幕页导出可临时改输出文件夹（默认仍走输出目录设置）

### 变更
- **全屏预览修复**（M19）：修复全屏后画面不满屏（高分辨率屏幕或低分辨率视频上缩在中间的问题）
- **设置页分组**（M19）：设置改为「通用 / AI 字幕」两个标签页
- **字幕页导出整合**（M19）：封装与烧录合并为一张导出卡，模式切换
