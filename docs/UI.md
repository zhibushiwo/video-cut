## 9. UI / UX 设计

### 9.1 窗口与布局

- `tauri.conf.json` 窗口需调整：**1280×800，最小 1024×680**（当前 800×600 放不下时间轴）
- 深色主题为主（视频工具惯例），Tailwind CSS 4 CSS-first 配置（`@theme` 定义色板），**无 tailwind.config 文件**
- **主题色切换（M4-8）**：强调色提供**预设**切换（默认 signal 绿 + 3~4 个备选），实现为运行时覆写 `:root` 的 `--color-signal`；signal（无损/就绪）与 warn（重编码）是**语义色**，warn 永不跟随主题色，预设色相避开 warn 琥珀以免混淆；`::selection` 与代码中硬编码的强调色（现有 `accent-[#4cc38a]`）须一并改为跟随 token
- **深浅主题（M10-2，B17 晋升，决策 #25）**：设置项三态 `深色 / 浅色 / 跟随系统`；跟随系统经 `matchMedia('(prefers-color-scheme: dark)')` 并监听变化实时切换；浅色 = 现有令牌集整体替换（新增 `.theme-light` 变量组），须对比度校对——warn 琥珀与四个主题色在浅底下的可读性逐一过检，signal 在浅底下必要时用加深变体；实现与主题色基建同源（同一组 CSS 变量，不引入第二套令牌体系）

### 9.2 页面流转

```text
Workbench（落地页）──右上角导航──▶ Cut / Merge / Editor(Rotate|Crop)
  ▲                                    │
  └──────────── 返回 ──────────────────┘
Workbench ──右上角──▶ History / Settings
（无路由库，顶层 state 切换；任务提交后可留在页面，由全局任务面板反馈；
 拖入视频一律落在当前页面，不再按数量跨页路由）
```

**页面保活（M10-1，决策 #24，2026-10-06 实施）**：四个工作页（Cut/Merge/Editor/Workbench）
离开时**隐藏不卸载**（非活跃页 display 隐藏，状态全保留），隐藏瞬间自动暂停
播放避免后台出声；History/Settings 为无状态视图，维持条件挂载。
设置变更一律即时生效、**不重置任何页面**（主题色等纯视觉变更零代价；
确需重建页面才能生效的设置必须二次确认——当前无此类项）。

**页面重置与换素材（M14-2，2026-09-28）**：与上一条**正交**——前者管"设置驱动"，本条管"用户显式发起"。四页统一：

- **两个动作分开**，不合成一个按钮：「换素材」（弹文件选择器）与「重置」（清当前操作产物）语义不同、破坏性不同；
- **换素材**：剪切/编辑页在**页头右侧**常驻「打开其他视频」（与空态那个入口同一处理函数，逐项清掉探测结果/关键帧/片段/选区/播放位置）；合并/工作台维持「添加」= **追加**，不清空既有列表；
- **重置**：**剪切 / 编辑页 = 卸载当前文件、回到本页空态**（可再点「打开视频文件」）——同时清掉本页全部编辑产物（剪切页：片段 + **删除列表**（`FR-326`）+ 选区 + 播放位置；编辑页：旋转回恒等 + 清选区 + 质量档位回设置值）；合并页 = 清空列表 + 文件名回默认；工作台 = **清空工程**（素材 + 片段 + 时间轴 + 撤销栈）；
- **二次确认**：存在"未导出的操作产物"时才弹（剪切页有片段**或删除标记** / 编辑页有非恒等旋转或选区 / 合并页有文件）；**工作台的「清空工程」始终确认**（破坏面最大，且必须连同撤销栈一起清——否则 Ctrl+Z 会"复活"已删片段，见 plans/M11.md §18.9 / `FR-1737`）；
- **落点**：剪切/编辑页重置后停在**本页空态**（可再点「打开视频文件」），工作台停在空工程态——**不跳页**（用户 2026-09-28 裁决）；
- 拖拽导入行为不变（落在当前页面原地分发）。

### 9.3 落地页 = 工作台（原 Home 已移除，v0.3）

- 应用启动直接进入工作台；品牌标识 + FFmpeg 环境徽标（原主页头部组件迁移至此）位于头部左侧
- 头部右上角为功能导航：剪切 / 合并 / 旋转 / 局部放大（图标+文字），分隔线后为历史记录 / 设置（图标按钮）
- 其余页面返回按钮统一指回工作台

### 9.4 Cut（最核心页面）

```text
┌──────────────────────────────────────────────┐
│  视频预览（VideoPlayer）          [模式: 极速▾] │
├──────────────────────────────────────────────┤
│  00:00:00 ──●━━━[========●──────]━━━━ 01:25:30│
│              ↑入点(吸附KF)  ↑出点              │
│  [开始时间 00:12:31.125] [结束时间 00:35:20.452]│
│  [+ 添加片段]                                 │
│  片段1  00:00:00 → 00:05:20   [🗑]            │
│  片段2  00:10:20 → 00:20:10   [🗑]            │
│  输出目录: D:\output  [更改]                   │
│                    [开始剪切]  ← 徽标: 无损     │
└──────────────────────────────────────────────┘
```

- 时间轴展示关键帧刻度（来自 `list_keyframes`）；入点手柄吸附最近关键帧，手柄旁 tooltip 显示实际落点时间
- "精确剪切"切换时出现橙色提示：将重编码、速度慢、字幕流将丢弃
- 模式徽标规则：极速=绿色"无损"，精确=橙色"重编码"
- **页头右侧**（文件名旁）：`打开其他视频` + `重置`（M14-2，语义与确认规则见 §9.2）
- **「开始=当前帧」/「结束=当前帧」两个按钮**（M14-4）：与开始/结束时间字段并列，一键把该端点设到播放头当前帧；与 `I`/`O` 快捷键**共用同一条钳制规则**（开始 ≤ 结束−0.1、结束 ≤ 时长），并沿用同一套按钮样式（与工作台源剪切视图的「入点=当前帧」「出点=当前帧」同形）
- **「提取 / 删除」模式（`FR-326` / `ADR-037`，M15-2）**：工具栏一个分段控件，**默认「提取片段」**（本节以上全部规则都是提取式，一字不改）。切到「**删除片段**」后：
  - **隐藏「极速 / 精确」组**——本模式固定**无损**（copy），页脚徽标恒为「无损」；理由：现有 pipeline 契约没有"强制重编码"入口，保留该开关会误导（精确边界归 `CAND-022`）
  - **标记**：用同一套双手柄选区（`I`/`O`、两个「=当前帧」按钮）选区间 → 点「**标记为删除**」加入删除列表；**至少在标记要保留的区间**（即删除区间的补集）与时间轴色带上实时可见
  - **删除列表**每行：`#序号 · 标记 [a,b] · 实际删除 [a,K] · 延伸 x.xs · 时长 · ✕`；`Delete`/`Backspace` 删最后一条；点击行 seek 到该区间起点
  - **时间轴**：删除区间画 warn 色带；**实际延伸段**（删除终点向后对齐到关键帧的那一截）用 warn 虚线标示——沿用提取式「实际落点」的明示手法（NFR-004）
  - **保留段汇总**：`成品 = N 段 · 总时长 m:ss` + 折行列出每段起止（只读）+ 无损性校验结果（`M15-3`：`checkPipeline` 全 copy ⇒ 「✓ 全程无损」；若报出需重编码的段则如实显示原因、页脚徽标随之改「重编码」——本模式预期不会发生，但不做静默假设）
  - **必须明示**：「无损删除：删除的**起点精确**，**终点会对齐到下一个关键帧**（最多多删 1 个 GOP，见列表里的实际范围）」
  - **门禁**：未标记 / 关键帧索引未就绪 / 全删光 → 导出按钮禁用并给出对应原因（关键帧未就绪时不允许导出——否则会产出"删不干净"的成品）
  - **导出**：成品名 `<源文件名>_trimmed.<扩展名>`（扩展名跟随源容器，`ADR-033`）；按钮文案「**导出保留部分**」
  - **两套列表各自保留**（切模式不清空），导出只作用于当前模式；删除列表**不入撤销栈**（剪切页无撤销栈，与提取列表同口径），回退手段 = 逐条 ✕ 或「重置」（§9.2，重置需**连两套列表一起清**）
  - **明确不做**：时间轴上直接拖拽已标记区间的边界（P2）；播放时自动跳过删除区间（归 M12-2）

- **添加片段自动续接**（M16-3，设置开关 `autoContinueClips` **默认开**）：「添加片段」成功后，入点自动跳到本次出点、出点自动推到视频结尾——逐段标注只需再拖出点一个手柄；关闭开关则维持原行为（区间不变）
- **剪切预览**（M16-8，`CAND-027②`）：片段 ≥ 1 时「生成预览」按**片段顺序连播**渲染一条预览（copy/重编码判定与导出一致，preview 缓存、不进面板与历史），用于导出前核对内容；**导出仍为每个片段一个独立文件**——预览是核对手段，不改变导出形态
- **合并预览**（M16-7，`CAND-027②`）：文件 ≥ 2 时「生成预览」按钮手动触发——文件列表即 pipeline 多输入条目（每文件全区间、无变换），与导出**同一条 copy/归一化判定**；产物为真实合并文件（preview 缓存，不进任务面板与历史，只留当前一份）。文件可能很大，故不自动渲染
### 9.5 Merge

- 文件列表（拖拽排序手柄 ☰、删除，排序用指针事件实现——决策 #18）；每项显示探测摘要（编码/分辨率/帧率）
- 底部检测面板：全部一致 → 绿色 ✓ 清单 + "可无损合并"；不一致 → 橙色 ⚠ + 差异项高亮 + [自动统一后合并] [取消]
- "自动统一"需二次确认，显示目标参数（默认=第一个文件参数）
- **默认输出文件名**（M14-3）：`<首个文件名>_merged.<扩展名>`——扩展名按 `ADR-033` 预判（参数一致 = copy 跟随源容器；不一致 = 重编码固定 `.mp4`），后端仍会校正兜底；**用户手动改过之后不再自动联动**；清空列表时复位。重名**不静默覆盖**，按决策 #19 只在撞名时追加时间戳
- **页头右侧**：`清空列表`（M14-2，有文件时二次确认）

### 9.6 Editor（Rotate / Crop 共用）

- 左侧大预览 + 右侧操作面板
- Rotate：五个方向按钮实时用 CSS transform 预览（纯前端预览，不生成视频），提交时才走 FFmpeg；显示"元数据级无损"
- Crop：预览上叠加可拖拽/缩放的选区矩形（经 VideoPlayer 的 overlay 插槽渲染：视频之上、控制条之下，不拦截播放控制），旁有 x/y/w/h 数值输入与比例锁定；显示"将重编码"徽标 + 质量档位选择
- **Crop 的预览双态（`FR-354` / `ADR-035`，M14-5）**：预览区一个切换控件在**编辑态**（全画面 + 可拖拽选区框，坐标即所见）与**预览态**（套用 `crop → scale` 后的画面 = 导出构图；选区框只读、不可拖）之间切换；切换**不重置选区**；提示沿用"预览为近似、导出以 FFmpeg 实际输出为准"
- **页头右侧**：`打开其他视频` + `重置`（M14-2，语义与确认规则见 §9.2）
- 时间轴不在此页（旋转/放大作用于全片，v1 不支持区间旋转/放大）

- **框选后可调整**（M16-6，`FR-354` 编辑态）：既有选区的**边缘**（约 8px 热区）拖拽 = 调整大小（逐边独立、不受比例锁影响），**框内**拖拽 = 平移（既有），**框外**按下 = 重画（既有）；边缘热区悬停光标 ew/ns-resize 反馈
### 9.7 TaskProgress（全局）

- 右下角可折叠抽屉；每任务一行：标签 + 进度条 + 百分比 + 速度 + 预计剩余（R3-4） + 取消按钮
- 失败时展开显示 ffmpeg stderr 最后若干行 + "复制日志"按钮
- Completed 项提供"打开所在文件夹"（`tauri-plugin-opener`）；点「打开位置」后**该行立即关闭**（M16-1，目标已达成无需再手动关）
- **内部任务不显示**（R3-3，DESIGN §8.2）：代理生成等 internal 任务的事件照常派发，面板凭 payload 的 `internal` 标记跳过——面板只反映用户可操作的导出类任务

### 9.8 Workbench（工作台，v0.3 = 2.0 布局）

页面自上而下四区 + 页脚（内容宽度放宽至 max-w-6xl）：

```text
┌────────────────────────────────────────────────────────┐
│ ① 成品预览（三态复用）                  [▶] 0:42/1:03  │ flex-1
├────────────────────────────────────────────────────────┤
│ ② 合成时间轴：刻度+片段块+播放头（块宽∝时长，拖拽排序）  │ ~72px
├────────────────────────────────────────────────────────┤
│ ③ 片段池：片段卡横排（缩略图/来源/区间/时长/徽标）       │ ~110px
├────────────────────────────────────────────────────────┤
│ ④ 素材卡片：首帧缩略图卡（拖拽排序/点击剪切）[+添加]     │ ~120px
├────────────────────────────────────────────────────────┤
│ 页脚：清空工程 · 质量档位 · 输出文件名 · [合成导出]                        │
└────────────────────────────────────────────────────────┘
```

- **① 成品预览区（三态复用，避免纵向空间再开一块）**，顶部面包屑标识当前模式：
  - **成品模式**（默认）：虚拟连播时间轴片段序列，**画面套用各片段的旋转与裁剪变换**——裁剪/放大按放大页同一映射呈现（即导出构图，不是在整帧上叠选区框，M14-5 修复 `BUG-015`）；双 `<video>` 轮换预加载下一段的源以隐藏切换延迟；播放头与②双向联动。
    **播到时间轴末尾即停；此时再按「播放」＝从成品起点重播**（暂停/拖动后按播放则是原地续播）——回退虚拟连播与「渲染即预览」单文件分支同口径（2026-10-06 补，原文未写重播落点 = [BUGS.md](./BUGS.md) `BUG-021`）
  - **源剪切模式**：点素材卡进入；播放该源 + `Timeline` 双柄选区间 + 关键帧吸附（受设置开关控制）+「添加为片段」（入池并追加时间轴末尾）
  - **片段加工模式**：点池卡或时间轴块进入；播放该片段 + 旋转（复用 RotateControls）/ 放大（显示空间框选，修改旋转清空选区）。
    **区间内预览（M9-5）**：加工视图播放限制在片段区间内——进入时定位入点，越过出点自动暂停（循环开关可选），不再放完整源视频。**进度条刻度、时间读数与键盘走带也一律以片段区间为准**（不是整源：选 5 秒的片段就该看到 0–5 秒的条与 `mm:ss / mm:ss` 读数），且拖拽/方向键**钳在区间内**、不存在"拖到外面再被弹回"；全段片段（`seg = null`）退化为整源刻度。（2026-10-05 补：原文只约束了"播放"，刻度仍按整源画 = [BUGS.md](./BUGS.md) `BUG-016`）
    **起播/重播的反馈口径（2026-10-06 补，`BUG-022`）**：越出出点后重播要先 `seek` 回入点，而回退解码到关键帧在长 GOP 源上可达 1.6~2s —— 这段时间**按钮必须立刻给出反馈**（起播当场发出 → 按钮即变「暂停」，`seek` 落地自动续播），**不得**"等 seek 落地才起播"（那期间按钮仍是「播放」、画面不动，用户连点又会打断尚未落地的 `play()`，表现为"无法重新播放"）。回退期间的旧位置上报只挡越界判定，不挡按钮反馈
    **两条播放入口同一条走带（2026-10-06 补，`BUG-023`）**：**点画面**与点「播放」按钮必须**等价**——同一套"停在出点先回入点 / 越界即停 / 循环"逻辑、同一个播放态。默认的"点画面只 `play()`"必须被覆盖掉，否则播完停在出点后点画面只起播一帧又被越界判定按停，"怎么点都重播不了"（`seg = null` 的全段片段因不参与越界判定而"看起来正常"，正是这个不一致把缺陷藏了三轮）。自然播放到底（`ended`）也算一次"播放停止"，播放态须如实回写（按钮回「播放」），点一次即重播
    **放大的预览双态（`FR-354`，M14-5）**：与放大页同源——编辑态（全画面 + 可拖选区）/ 预览态（套用 `crop → scale` 的导出构图，选区只读），切换不重置选区

### 9.9 设置（M4-1 基础 + M4-8 二期）

- 页内为"标题+说明 | 控件"的行式布局，**改动即保存**（write-through，无显式保存按钮）
- 配置项（定义见 DESIGN.md §12）：
  - **默认输出目录**：目录选择器 + 清除按钮。输出位置规则：设置了默认目录则**所有页面**输出到该目录，否则跟随源文件所在目录（剪切/合并/旋转/放大/工作台一致）
  - **默认剪切模式**（极速/精确）与**入点吸附关键帧**（开关）→ 剪切页初始值
  - **代理预览**：自动（按格式支持性按需生成）/ 始终代理（4K 预览卡顿时用）/ 关闭（不生成代理；不支持的格式显示占位提示条，导出不受影响）
  - **编码器**：自动（按位深选 H.264/HEVC 并探测 GPU，失败回退软件）或锁定指定编码器；经任务载荷下发，Rust 侧 `effective_encoder` 校验后采用，非法值回退自动
  - **默认质量档位** → Editor（旋转重编码/放大）与工作台质量选择的初始值
  - **主题色**（M4-8）：强调色预设单选（§9.1），即时生效并持久化
  - **任务浮层自动关闭**（M7-5）：秒数输入（0 = 不关闭，默认 0），终态任务浮层到时自动消失
  - **添加片段自动续接**（M16-3）：开关，默认开——「添加片段」后入点接上次出点、出点推到视频结尾（§9.4）
- **缓存管理区**（M4-8）：显示代理文件 + 缩略图占用（`cache_usage`），「清理缓存」按钮（`clear_cache`，ask 二次确认，被占用文件跳过并提示数量）；清理后刷新占用显示
- **页尾静态区**（M4-8）：重置全部设置（ask 二次确认 → 写回默认值）；关于——应用版本、FFmpeg/ffprobe 版本、"所有处理在本机完成"声明、内置 FFmpeg 构建的 GPL 许可注记（DESIGN.md §11）
